NSE Scripts

Nmap Scripting Engine — From basic usage to powerful real-world scripts

What is NSE?

The Nmap Scripting Engine (NSE) is one of the most powerful features of Nmap. It allows you to run scripts (written in Lua) to perform advanced tasks such as:

  • Service detection & version detection
  • Vulnerability scanning
  • Advanced network discovery
  • Brute force attacks (use carefully)
  • Malware detection
  • And much more

Scripts are located in: /usr/share/nmap/scripts/ (Linux) or the scripts folder in your Nmap installation.

How to Use Scripts

1. Default scripts (recommended starting point)

nmap -sC target.com
nmap -sC -sV target.com

2. Run a specific script

nmap --script=http-enum -p 80,443 target.com
nmap --script=smb-os-discovery -p 445 target.com

3. Run multiple scripts

nmap --script=http-title,http-headers,ssl-cert -p 80,443 target.com

4. Run a whole category

nmap --script=vuln target.com
nmap --script=discovery target.com
nmap --script=safe target.com

5. Advanced filtering

nmap --script="http-* and not brute" target.com
nmap --script="not intrusive" target.com

Most Useful Scripts

http-enum

nmap --script=http-enum -p 80,443 target.com

Discovers hidden directories and files on web servers (very useful for recon).

http-title

nmap --script=http-title -p 80,443,8080 target.com

Retrieves the title of web pages. Great for quick identification.

http-headers

nmap --script=http-headers -p 80,443 target.com

Shows HTTP response headers.

ssl-cert

nmap --script=ssl-cert -p 443 target.com

Displays detailed SSL/TLS certificate information.

ssl-heartbleed

nmap --script=ssl-heartbleed -p 443 target.com

Checks for the Heartbleed vulnerability.

smb-os-discovery

nmap --script=smb-os-discovery -p 445 target.com

Detects operating system and computer name over SMB.

smb-vuln-*

nmap --script=smb-vuln* -p 445 target.com

Checks for common SMB vulnerabilities (MS17-010, etc.).

banner

nmap --script=banner -p 21,22,25,80,110,143 target.com

Grabs service banners from open ports.

dns-brute

nmap --script=dns-brute target.com

Attempts to discover subdomains by brute-forcing DNS.

whois-ip / whois-domain

nmap --script=whois-ip target.com
nmap --script=whois-domain target.com

Performs WHOIS lookups.

vuln (category)

nmap --script=vuln -sV target.com

Runs a large set of vulnerability detection scripts.

http-robots.txt

nmap --script=http-robots.txt -p 80,443 target.com

Checks for robots.txt and lists interesting entries.

Script Categories

You can run entire categories at once:

nmap --script=auth target.com
nmap --script=broadcast target.com
nmap --script=brute target.com
nmap --script=default target.com
nmap --script=discovery target.com
nmap --script=dos target.com
nmap --script=exploit target.com
nmap --script=external target.com
nmap --script=fuzzer target.com
nmap --script=intrusive target.com
nmap --script=malware target.com
nmap --script=safe target.com
nmap --script=version target.com
nmap --script=vuln target.com

Tip: Start with safe, discovery or default.

Useful NSE Commands

# List all available scripts
ls /usr/share/nmap/scripts/

# Get help for a specific script
nmap --script-help http-enum

# Get help for a category
nmap --script-help vuln

# Show script arguments
nmap --script-help http-enum | grep -A 20 Arguments

Tips & Best Practices

  • Always combine scripts with -sV when possible for better results.
  • Use -sC as your default (it runs the "default" category).
  • Be very careful with brute, intrusive and dos scripts.
  • Some scripts need arguments: --script-args
  • Example with arguments:
    nmap --script=http-enum --script-args http-enum.basepath=/admin/ target.com
  • You can update scripts with: nmap --script-updatedb
