NCRC PCAP Analyzer Help

Getting Started

  1. Load a PCAP file by dragging & dropping or clicking upload
  2. The analyzer will parse and dissect all packets
  3. Browse different tabs to analyze specific aspects
  4. Use filters to focus on specific traffic
  5. Export results in your preferred format

Features

  • Overview: Visual summary of traffic
  • Protocols: Protocol distribution analysis
  • IPs: Source and destination IP analysis
  • Ports: Port and service analysis
  • Conversations: Traffic flow between IPs
  • Packets: Detailed packet inspection
  • DNS: DNS query and response analysis
  • HTTP: HTTP request and response analysis
  • Security: Threat detection and anomalies
  • Export: Export results in multiple formats
