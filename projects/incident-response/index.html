The 5 Phases of Incident Response

🚨

Detection

Alert is triggered by SIEM/EDR. Something suspicious detected. This is when you get the notification.

Minute 0-5
🔍

Validation

Is this a real threat or false positive? Run validation commands to confirm the attack is happening.

Minute 5-15
🛑

Containment

Stop the attack from spreading. Disconnect compromised systems, revoke credentials, block IPs.

Minute 15-30
🧹

Eradication

Remove the threat completely. Delete malware, patch vulnerabilities, reset passwords.

Hour 1-4
🔐

Recovery

Restore systems to normal. Monitor for reinfection. Implement preventive measures.

Hour 4+
