Introduction

Qu'est-ce que Gobuster ?

Gobuster est un outil de brute-force écrit en Go, extrêmement rapide et polyvalent. Il est principalement utilisé pour :

  • Découvrir des répertoires et fichiers cachés (mode dir)
  • Énumérer des sous-domaines (mode dns)
  • Découvrir des virtual hosts (mode vhost)
  • Fuzzer des paramètres (mode fuzz)

Il est devenu un classique des phases de reconnaissance en pentest web et bug bounty.

💡 Pourquoi Gobuster ?
Très rapide grâce à Go, faible consommation mémoire, support des proxies, des cookies, des headers personnalisés, et excellent pour les scans silencieux.

Installation

Méthode 1 : Go Install (recommandée)

go install github.com/OJ/gobuster/v3@latest

Méthode 2 : Apt (Kali / Debian)

sudo apt update && sudo apt install gobuster -y

Méthode 3 : Depuis les sources

git clone https://github.com/OJ/gobuster.git
cd gobuster
go build
sudo mv gobuster /usr/local/bin/
⚠️ Note : Vérifie toujours la version avec gobuster version

Modes Gobuster

Gobuster propose plusieurs modes puissants. Clique sur un mode pour voir les détails.

📁

dir

Directory / File brute-force

🌐

dns

Subdomain enumeration

🖥️

vhost

Virtual Host discovery

⚡

fuzz

Fuzzing de paramètres

Mode DIR – Directory Brute-Force

Le mode le plus utilisé. Il teste l’existence de chemins sur un serveur web.

gobuster dir -u https://target.com -w /usr/share/wordlists/dirb/common.txt

Exemple avancé

gobuster dir -u https://target.com \
  -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt \
  -x php,html,txt,bak,zip \
  -t 50 \
  -b 403,404 \
  --timeout 10s \
  -o gobuster_dir.txt
Mode DNS – Subdomain Enumeration

Énumère les sous-domaines en interrogeant les serveurs DNS.

gobuster dns -d target.com -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt
gobuster dns -d target.com \
  -w wordlist.txt \
  -t 30 \
  --delay 100ms \
  -o subdomains.txt
Mode VHOST – Virtual Host Discovery

Découvre des virtual hosts en envoyant des headers Host différents.

gobuster vhost -u https://target.com -w vhosts.txt
Mode FUZZ – Parameter Fuzzing

Permet de fuzzer des paramètres dans l’URL ou le body.

gobuster fuzz -u https://target.com/api?FUZZ=test -w params.txt

Flags les plus utiles

Flag Description Exemple
-u URL cible -u https://target.com
-w Wordlist -w wordlist.txt
-t Nombre de threads -t 50
-x Extensions à tester -x php,html,txt,bak
-b Codes HTTP à ignorer (blacklist) -b 403,404
-s Codes HTTP à afficher (whitelist) -s 200,301,302
-c Cookies -c "session=abc123"
-H Header personnalisé -H "Authorization: Bearer token"
-k Ignore les certificats SSL invalides -k
-o Fichier de sortie -o results.txt
--timeout Timeout des requêtes --timeout 10s
--delay Délai entre les requêtes --delay 50ms
-q Mode silencieux (quiet) -q
--no-error N’affiche pas les erreurs --no-error

Exemples Pratiques

Scan classique de répertoires
gobuster dir -u https://target.com -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt -t 40
Scan avec extensions + ignore 403/404
gobuster dir -u https://target.com \
  -w raft-large-directories.txt \
  -x php,asp,aspx,jsp,html,js,txt,bak,old,zip \
  -b 403,404 \
  -t 60 \
  -o found.txt
Subdomain enumeration rapide
gobuster dns -d target.com \
  -w /usr/share/seclists/Discovery/DNS/bitquark-subdomains-top100000.txt \
  -t 50 \
  -o subs.txt
Scan authentifié avec cookie + header
gobuster dir -u https://target.com/admin \
  -w common.txt \
  -c "PHPSESSID=abc123; security=low" \
  -H "X-Forwarded-For: 127.0.0.1" \
  -t 30

Tips & Tricks

1. Éviter d’être détecté
gobuster dir -u https://target.com -w wordlist.txt -t 10 --delay 200ms
2. Scanner en passant par un proxy (Burp)
gobuster dir -u https://target.com -w wordlist.txt --proxy http://127.0.0.1:8080
3. Ignorer les certificats SSL invalides
gobuster dir -u https://target.com -w wordlist.txt -k
4. Afficher seulement certains codes de statut
gobuster dir -u https://target.com -w wordlist.txt -s 200,204,301,302,307
⚠️ Rappel légal : N’utilise Gobuster que sur des cibles pour lesquelles tu as une autorisation écrite.
