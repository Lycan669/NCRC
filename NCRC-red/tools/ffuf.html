Introduction

Qu'est-ce que ffuf ?

ffuf (Fuzz Faster U Fool) est l'un des fuzzers web les plus rapides et les plus appréciés actuellement. Il est écrit en Go et excellent pour :

  • Directory & file discovery
  • Virtual host enumeration
  • Parameter fuzzing
  • Fuzzing de valeurs (POST, headers, cookies...)

Il est plus flexible et souvent plus rapide que Gobuster sur beaucoup de scénarios.

💡 Point fort de ffuf : Très bonne gestion des filtres (taille, mots, lignes, status code, regex) et support natif de multiples positions de fuzzing (FUZZ).

Installation

Go Install (recommandé)

go install github.com/ffuf/ffuf/v2@latest

Avec apt (Kali)

sudo apt update && sudo apt install ffuf -y

Depuis les sources

git clone https://github.com/ffuf/ffuf.git
cd ffuf
go build
sudo mv ffuf /usr/local/bin/

Brute-force de chemins

VHost

Paramètres

Fuzzing de paramètres

Values

Fuzzing de valeurs

Directory / File Discovery
ffuf -u https://target.com/FUZZ -w wordlist.txt
ffuf -u https://target.com/FUZZ -w raft-medium-directories.txt -e .php,.html,.txt,.bak -mc 200,301,302,403
Virtual Host Enumeration
ffuf -u https://target.com -w vhosts.txt -H "Host: FUZZ.target.com" -fs 4242

Le -fs permet d’ignorer les réponses de taille identique (très utile).

Parameter Fuzzing
ffuf -u https://target.com/api?FUZZ=test -w params.txt -mc all
Value Fuzzing (POST / Headers / Cookies)
ffuf -u https://target.com/login -X POST -d "username=admin&password=FUZZ" -w passwords.txt -mc 200

Flags les plus importants

Flag Description
-uURL cible (utiliser FUZZ pour la position)
-wWordlist
-eExtensions (ex: .php,.bak)
-tNombre de threads
-mcMatch status codes (ex: 200,301,403)
-fcFilter status codes
-fsFilter size (très puissant)
-fwFilter word count
-flFilter line count
-frFilter regex
-HHeader personnalisé
-bCookie
-XMéthode HTTP (GET, POST...)
-dData (body POST)
-kIgnore SSL certificate errors
-oOutput file
-ofOutput format (json, html, md...)
-sSilent mode
-pDelay between requests

Exemples concrets

Directory brute-force classique
ffuf -u https://target.com/FUZZ -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt -t 50
Avec extensions + filtre de taille
ffuf -u https://target.com/FUZZ -w wordlist.txt -e .php,.html,.txt,.bak,.zip -mc 200,204,301,302,403 -fs 0
Virtual Host discovery
ffuf -u https://10.10.10.10 -w subdomains.txt -H "Host: FUZZ.target.com" -fs 12345
POST login fuzzing
ffuf -u https://target.com/login -X POST -d "user=admin&pass=FUZZ" -w passwords.txt -fc 401
Fuzzing de header
ffuf -u https://target.com -w wordlist.txt -H "X-Custom-Header: FUZZ"

Filtres puissants

Les filtres sont l’une des plus grandes forces de ffuf.

Filtres les plus utilisés
FlagUtilité
-mcMatch seulement certains status codes
-fcIgnore certains status codes
-fsIgnore les réponses d’une certaine taille
-fwIgnore selon le nombre de mots
-flIgnore selon le nombre de lignes
-frIgnore selon une regex
Astuce pro : Lance d’abord un petit scan pour voir la taille des fausses réponses, puis utilise -fs pour les éliminer.

Tips & Bonnes pratiques

1. Scanner plus discrètement
ffuf -u https://target.com/FUZZ -w wordlist.txt -t 10 -p 0.2
2. Sortie colorée + silencieuse
ffuf -u https://target.com/FUZZ -w wordlist.txt -c -s
3. Sauvegarder en JSON
ffuf -u https://target.com/FUZZ -w wordlist.txt -o results.json -of json
4. Utiliser plusieurs wordlists
ffuf -u https://target.com/FUZZ -w list1.txt:FUZZ -w list2.txt:FUZ2Z
Rappel : Utilise ffuf uniquement sur des cibles autorisées.
