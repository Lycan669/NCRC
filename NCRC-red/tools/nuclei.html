Introduction

Qu'est-ce que Nuclei ?

Nuclei est un scanner de vulnérabilités ultra-rapide basé sur des templates YAML. C’est actuellement l’une des armes les plus puissantes en bug bounty.

Il permet de détecter automatiquement :

  • CVEs connues
  • Misconfigurations
  • Exposures (fichiers sensibles, panels, etc.)
  • Default credentials
  • Subdomain takeovers
  • Technologies vulnérables
  • Et des milliers d’autres checks
Pourquoi Nuclei est obligatoire dans ton arsenal ?
Tu peux scanner des centaines de cibles en quelques minutes avec des milliers de checks. C’est le meilleur rapport vitesse / résultats actuellement.

Installation

Méthode recommandée (Go)

go install -v github.com/projectdiscovery/nuclei/v3/cmd/nuclei@latest

Avec pdtm

pdtm -i nuclei

Mise à jour des templates (très important)

nuclei -update-templates
Important : Toujours mettre à jour les templates avant un concours ou un scan important.

Usage Basique

Scanner une cible unique
nuclei -u https://target.com
Scanner une liste de cibles
nuclei -l live-hosts.txt
Mode silencieux + sauvegarde
nuclei -l live-hosts.txt -silent -o results.txt
Lire depuis stdin (pipeline)
cat live-hosts.txt | nuclei -silent

Templates (le cœur de Nuclei)

Catégories de templates les plus utiles
Dossier / Tag Utilité
cves/ Vulnérabilités CVE connues
vulnerabilities/ Vulns diverses
exposures/ Fichiers et panels exposés
misconfiguration/ Mauvaise configuration
takeovers/ Subdomain takeover
default-logins/ Identifiants par défaut
technologies/ Détection de technologies
fuzzing/ Fuzzing basique
Lancer des templates spécifiques
nuclei -l hosts.txt -t cves/ -t exposures/ -t misconfiguration/
Utiliser des tags
nuclei -l hosts.txt -tags cve,exposure,config,panel
Exclure certains templates
nuclei -l hosts.txt -exclude-tags dos,fuzz

Flags les plus importants

Flag Description
-uCible unique
-lListe de cibles
-tTemplates à utiliser
-tagsFiltrer par tags
-exclude-tagsExclure des tags

-silentMode silencieux

-jsonSortie JSON

-bsBulk size (requêtes parallèles)

Exemples de Guerre

1. Scan rapide critique + high
nuclei -l live.txt -severity critical,high -silent -o critical-findings.txt
2. Scan CVEs + Exposures + Misconfigurations
nuclei -l live.txt -t cves/ -t exposures/ -t misconfiguration/ -silent -o results.txt
3. Scan automatique selon les technologies
nuclei -l live.txt -as -silent
4. Scan très agressif (beaucoup de templates)
nuclei -l live.txt -t cves/,vulnerabilities/,exposures/,misconfiguration/,default-logins/ -c 50 -bs 25 -silent
5. Seulement les panels / login pages
nuclei -l live.txt -tags panel,login,admin -silent

Pipelines Complets (Arsenal)

Pipeline classique ultra efficace
subfinder -d target.com -silent | httpx -silent | nuclei -severity critical,high,medium -silent -o findings.txt
Pipeline avec sauvegarde intermédiaire
subfinder -d target.com -silent -o subs.txt
cat subs.txt | httpx -silent -o live.txt
nuclei -l live.txt -t cves/,exposures/,misconfiguration/ -silent -o nuclei.txt
Pipeline rapide pour concours
subfinder -d target.com -silent | \
httpx -silent -title -status-code | \
nuclei -severity critical,high -c 40 -silent

Tips de Guerre (Hack ton lycée)

1. Toujours mettre à jour les templates avant le concours
nuclei -update-templates
2. Commence toujours par critical + high
nuclei -l live.txt -severity critical,high -silent
3. Utilise -as pour scanner selon les technologies détectées
nuclei -l live.txt -as -silent
4. Augmente la vitesse (attention à ne pas te faire ban)
nuclei -l live.txt -c 50 -bs 25 -rate-limit 150
Stratégie recommandée pour le concours :
1. subfinder → httpx (live hosts)
2. nuclei (critical + high + exposures)
3. ffuf sur les cibles intéressantes
4. Analyse manuelle des findings
Rappel important : Utilise Nuclei uniquement sur les cibles autorisées du concours.
